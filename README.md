# @chief-strategist-j/shared-infra

Core engine: HTTP client, adapters, decorators, event bus, rules engine, feature flags, centralized OpenTelemetry & messaging tracing.

## Installation

```bash
npm install @chief-strategist-j/shared-infra
```

## Features

- **Data-Driven Pipelines & Transforms**: Deep JSON remapping, array operations, DAG transformations.
- **Resilience Decorators**: `withRetry`, `withCache`, `withCircuitBreaker`, `withTracing`.
- **Event Bus & Messaging**: Cross-feature decoupled pub/sub event bus with OpenTelemetry trace propagation.
- **Rules Engine & Feature Flags**: High-performance rule evaluation and flag resolution.
- **Centralized Telemetry**: Built-in OpenTelemetry tracing integration.
